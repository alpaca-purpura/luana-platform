If the architect didn't QA the kit against comunify's theme, a control might render square (reading `--radius` instead of using the pill class). This isn't a builder bug; it's a kit bug. Architect to verify.

4. **Be paranoid about cross-brand imports.** nicolify + vitalia are listed as references, not imports. IDE autocomplete might suggest `import { Ribbon } from "@/../nicolify/frontend/..."`. Reject it. Anti-dup Cat 12 + FSD boundaries will fail auditor review. Only import from kit or engine.
