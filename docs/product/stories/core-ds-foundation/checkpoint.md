Todos `[--x]` → `(--x)`. (T-3 drift-lint `no-arbitrary-value` los hubiera cazado; ya no quedan bare-var en `src/`.)
2. ✅ **`src/timezone-select.tsx` — tsc** `Intl.supportedValuesOf` requería lib ES2022. **Fix:** `tsconfig.json` `target`/`lib` ES2020 → ES2022. Resuelve también el `any` implícito del `.map` (ahora `supportedValuesOf` tipa `string[]`).
3. ✅ **test files — tsc** matchers `@testing-library/jest-dom` invisibles a tsc. **Doble causa:** `vitest.setup.ts` importaba `@testing-library/jest-dom` (augmenta jest, no la `Assertion` de vitest) + el setup no estaba en `tsconfig.include`. **Fix:** import → `@testing-library/jest-dom/vitest` + `vitest.setup.ts` agregado a `include`.
